# Analýza docházky

Jednoduchá konzolová aplikace v Pythonu pro zpracování docházky zaměstnanců z CSV souboru.

## Požadavky

- Nainstalovaný Python 3
- Knihovny uvedené v `requirements.txt`

## Instalace a spuštění

**1.** Stáhněte projekt z GitHubu a otevřete jeho složku v terminálu.

**2.** Vytvořte virtuální prostředí:

```bash
py -m venv .venv
```

**3.** Aktivujte virtuální prostředí (Windows CMD):

```cmd
.venv\Scripts\activate.bat
```

**4.** Nainstalujte potřebné knihovny:

```bash
python -m pip install -r requirements.txt
```

**5.** Spusťte aplikaci:

```bash
python dochazka.py dochazka.csv
```
